Project definition:
Swimphony uses one ordinary camera to track one goldfish and transform its movement into generative sound and ambient light. The submission must be usable without special hardware through sample video, recorded telemetry, and Virtual Light. Philips Hue is optional. Two-camera 3D tracking and iPhone TrueDepth are deferred.

Core architecture:
Video or camera input -> tracker -> shared FishState -> performance mapper -> Tone.js audio + Virtual Light + optional Hue.
Natural-language mood prompt -> server-side OpenAI Responses API using GPT-5.6 -> validated PerformancePreset -> performance mapper.

Non-negotiable constraints:
- Preserve the runnable telemetry demo.
- Do not expose API keys to client code.
- Do not use flashing or rapid light changes.
- Do not implement user accounts, cloud persistence, two-camera tracking, TrueDepth, or multi-fish identity tracking.
- Work phase by phase.
